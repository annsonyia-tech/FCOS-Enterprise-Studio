# 1. Purpose

This document serves as the enterprise knowledge base for Product Types within FCOS AI Studio Enterprise.

It provides standardized commercial product types, fashion taxonomy, product relationships, regional terminology, construction-based classifications, luxury retail mappings, marketplace mappings, and emerging product categories used by the FCOS Product Type Intelligence Engine.

This document contains product knowledge only and does not define processing rules.
