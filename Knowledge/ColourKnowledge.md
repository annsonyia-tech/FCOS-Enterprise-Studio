# 1. Purpose

This document serves as the enterprise colour knowledge base for FCOS AI Studio Enterprise.

It provides standardized commercial colour terminology, colour normalization, colour families, luxury colour naming, regional colour terminology, and fashion-specific colour intelligence used by the FCOS Fashion Intelligence Engine.

This document contains colour knowledge only and does not define processing rules.
